# ⚠️ این برنچ استفاده نمی‌شود

کل پروژه روی برنچ **`master`** است.

```bash
git clone -b master https://github.com/MErfanPld/webspeed-eshop.git
cd webspeed-eshop
npm install
npm run dev
```

برای حذف کامل این برنچ:
1. در GitHub → Settings → General → Default branch را روی `master` بگذارید
2. سپس Branches → main → Delete
